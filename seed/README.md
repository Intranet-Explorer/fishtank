# Seed habitat

Fictional **Pinefen Supply Co.** receiving-dock corpus. This is the starting mess for a new tank.

`scripts/fresh.sh` (or `python -m world.seed`) copies these files into `habitat/`, which is the live workspace and is gitignored.

Do not commit live corkboard stamps, mail, outbox dumps, or private diaries. Put experiment leftovers in `habitat/` and reset with `./scripts/fresh.sh`.
